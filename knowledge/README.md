# 论文格式知识库目录

把**国标 / 学校格式规范 PDF**（如 GB/T 7714—2015、GB/T 7713.1—2006、本校学位论文写作规范）
直接拷贝到本目录（`knowledge/`）。

- 服务启动时会自动提取每个 PDF 的文本，并缓存为同名 `*.extracted.txt`
  （扫描件会走 OCR，首次较慢；之后读缓存，秒级）。
- 新增/替换 PDF 后，在「问答模式」点击「重新扫描」即可生效，无需重启。
- 「问答模式」会把这些资料 + 内置国标要点一起作为知识库回答用户问题。
- 用户可在「问答模式」点「查看原件」直接打开 PDF。

> 内置要点（GB/T 7714 / GB/T 7713 / 通用排版规范）已开箱即用，
> 即使本目录为空也能使用问答模式；放入 PDF 只是扩充与提供原件查阅。

`*.extracted.txt` 为自动生成的缓存文件，可随时删除（会自动重建）。
